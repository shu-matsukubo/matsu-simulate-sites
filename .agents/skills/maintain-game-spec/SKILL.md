# Game Specification Maintenance

ゲーム仕様・シミュレーションルールに関係する変更では、
現在の仕様文書と実装を両方確認する。

- 実装が既存仕様と矛盾していないか確認する
- 仕様を変更した場合は仕様文書も更新する
- 実装だけに存在する重要なルールを放置しない
- 文書だけに存在し、実装されていない仕様を現在仕様として扱わない
- 計算式・係数・条件分岐など、ゲーム結果に影響するルールは仕様側から追える状態にする

UI構造、使用技術、内部実装方式など、
ゲーム仕様ではない事項は原則として文書化を要求しない。
